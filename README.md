# GoPet Offline + QLTK

**Tải bản cài:** [QLTK-Setup.exe](https://github.com/kentq2552/GoPet-QLTK/raw/main/QLTK-Setup.exe) · phiên bản **1.2.1** (2026-10-25)

Cài xong là chơi: QLTK kèm sẵn game GoPet (bản mở rộng pet), giả lập AngelChip và Java.
QLTK tự kiểm tra bản mới trên repo này và cập nhật bằng nút **Cập nhật ngay**, acc và save giữ nguyên.

Danh sách đồ trong tab Admin đổi sang kiểu khung nâng cấp: nền sáng, ô icon tổ ong, hiện chỉ số (Tấn công/Giáp/HP/MP) và mô tả từng món. Sửa thanh "Cập nhật ngay" hiện nhầm khi đã là bản mới nhất.
