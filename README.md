# GoPet Offline + QLTK

**Tải bản cài:** [QLTK-Setup.exe](https://github.com/kentq2552/GoPet-QLTK/raw/main/QLTK-Setup.exe) · phiên bản **1.2.0** (2026-10-25)

Cài xong là chơi: QLTK kèm sẵn game GoPet (bản mở rộng pet), giả lập AngelChip và Java.
QLTK tự kiểm tra bản mới trên repo này và cập nhật bằng nút **Cập nhật ngay**, acc và save giữ nguyên.

Bản đầu có tự cập nhật. Tab Admin: hình vật phẩm chia theo mục, thêm pet, sửa cấp/bậc/sao, cộng lực chiến, dịch chuyển, auto map theo cấp pet, giảm hồi chiêu và tăng tốc auto.
